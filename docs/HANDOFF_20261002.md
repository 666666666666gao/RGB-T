## 当前新增代码：C1，完整模块尚未实现

`research/candidate_learning.py`、`research/train_candidate.py`、`scripts/run_c1_sanity.sh`、`scripts/run_c1_initial.sh` 已编写，部署前独立代码审查进行中。

C1 从完整 pretrained GOLA 的冻结特征训练候选质量与排序头。原赢家始终保留，其余来自空间不同局部峰，NMS/网格距离去重，最多5候选，不足候选使用 mask。使用首帧模板、较早帧在线模板、当前搜索图；输入质量头不含 GT/未来标签。两个传感器独立 patch 相似度来自联合注意力之前，不能把混合后 tokens 说成独立 RGB/TIR 证据。

候选标签是真实框 IoU，不是是否被 GOLA 选中。30% 在线模板平移扰动是合成污染，不代表已训练真实模型失败轨迹。首帧无有效目标框/不足两次有效观测的序列不进入 C1；实际可用序列数写 `config.json`。

### 实验设置

| 参数 | C1 sanity | C1 initial |
|---|---:|---:|
| GPU | 物理 GPU1（进程内部 cuda:0） | 同左 |
| epochs × steps | 1×8 | 3×512 |
| batch | 4 | 8 |
| val steps | 2 | 32 |
| workers | 2 | 4 |
| seed / lr / wd | 42 / 1e-4 / 1e-4 | 同左 |
| hidden / K | 128 / 5 | 同左 |
| Hann / NMS IoU | .45 / .7 | 同左 |
| loss | soft-IoU BCE + pair ranking（gap .1，weight1） | 同左 |
| 训练数据 | LasHeR train 内序列划分 90% | 同左 |
| 验证数据 | 剩余10% train 序列，固定采样 | 同左 |

初始新头末层为0，保留原Hann选择；优化器只接新头参数。base 全部 requires_grad=False、eval，无梯度，结果证明新头参数实际变化。输出包括 `config.json`、`split.json`、`train.jsonl`、`metrics.json/csv`、`epoch_*.pth`、`best.pth`、`completion.json`。

指标为 held-out **候选级诊断**：baseline/learned/oracle IoU、Recall@K、基线失败时正确未选候选数、重新选对率、原本正确被错改率、候选数量。完整样本数/分母保留，分母0用 null。**这些不是 LasHeR PR/SR，也不证明严格在线漂移恢复。**

必须如实保留当前缺口：A 尚未实现；B 尚未实现；C 的多帧有限分支、运动/在线模板恢复、短期展开价值监督尚未实现。C1 不能作为整套 A+B+C 的论文结果。下一步根据候选诊断接 C2 状态恢复，再接 A/B。
